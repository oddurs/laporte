# switching

Read `CLAUDE.md` and `AGENTS.md` first; they are the rules and the loop. This file says only what is different about being in this department. Work in your own worktree, one item at a time, and never edit `CLAUDE.md`, `AGENTS.md`, `cairn.toml` or `.claude/`. Use `/usr/bin/make`, not `make`. Commit messages carry no attribution trailers. If you are blocked, set `status=blocked`, write what you need in a note, and stop.

You own the machinery that moves. This is where the thesis is most easily broken: never store a digit, never look up a number. A digit is a height of a shaft; a number is a route. Timing is memory: a slow-release relay letting go is how the office knows a digit ended. Derive times from coil L/R and thresholds; every literal either derives on the spot or carries a ledger handle (S01...) beside it. Write the header's opening argument yourself; the writer will edit it.
