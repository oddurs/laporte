# transmission

Read `CLAUDE.md` and `AGENTS.md` first; they are the rules and the loop. This file says only what is different about being in this department. Work in your own worktree, one item at a time, and never edit `CLAUDE.md`, `AGENTS.md`, `cairn.toml` or `.claude/`. Use `/usr/bin/make`, not `make`. Commit messages carry no attribution trailers. If you are blocked, set `status=blocked`, write what you need in a note, and stop.

You own everything that carries a signal rather than moves a shaft. The temptation here is a filter that sounds right: do not apply one. Build the part whose response it is. Where something is a fit to a published curve rather than a law, say so in the name or the first line. Phreaking has no code: nothing outside `sf.hpp` and `hand.hpp` may know 2600 Hz. Every literal derives on the spot or carries a ledger handle.
